瑞幸：C 罗 / 亚马尔杯套与保温杯

把两队和两代球星的阵营选择变成咖啡杯上的公开表达

部分核验葡萄牙 x 西班牙国家队 / 门店周边待补品牌原片与投放现场

案例发生了什么

瑞幸围绕葡萄牙和西班牙国家队推出 C 罗、亚马尔主题杯套与保温杯，让门店消费成为球迷站队动作；它与夺冠免单属于不同的商品与身份表达机制。

案例启示

案例启示

关键动作
  • 以“葡萄牙 x 西班牙国家队 / 门店周边”建立进入世界杯讨论的明确资格。
  • 把“把两队和两代球星的阵营选择变成咖啡杯上的公开表达”落实到杯套、保温杯、门店、App 点单、社交晒单与会员，避免只停留在赛事口号。
  • 面向葡萄牙、西班牙球迷、咖啡用户与年轻消费者设计看见、参与与行动三层触点。

传播与商业机制

传播路径

以“葡萄牙 x 西班牙国家队 / 门店周边”为资源起点，进入杯套、保温杯、门店、App 点单、社交晒单与会员，让赛事权益转化为用户可接触、可讨论或可参与的内容。

商业承接

不把曝光直接等同销售，重点观察周边领取、售罄、订单增量、会员、用户共创内容与复购，并区分品牌自报、平台数据与可独立核验结果。

可复用的方法高频杯身是低成本应援媒体，但要通过领取规则和产品设计把曝光转成到店与复购。

适用条件、风险与证据

  • 先明确目标是国内动销、出海认知、渠道关系还是授权商品，而不是全部都做。
  • 球星或球队的赛果只是放大器，必须准备常态内容和转化出口。
  • 对授权范围、地域、肖像和商品库存建立可追溯台账。
核验记录可将已核动作作为内部判断基础；涉及投放规模、销售结果或合作细则时，仍应以品牌、平台或权利方的一手发布为准。 当前记录：部分已核（行业复盘；商品款式、领取门槛和销售数据待官方补证）；素材状态：待补品牌原片与投放现场。
