瑞幸：C 罗 / 亚马尔杯套与保温杯

把两队和两代球星的阵营选择变成咖啡杯上的公开表达

部分核验葡萄牙 x 西班牙国家队 / 门店周边待补品牌原片与投放现场

案例发生了什么

瑞幸围绕葡萄牙和西班牙国家队推出 C 罗、亚马尔主题杯套与保温杯，让门店消费成为球迷站队动作；它与夺冠免单属于不同的商品与身份表达机制。

它解决的策略问题

这页要回答的不是“瑞幸：C 罗 / 亚马尔杯套与保温杯 是否参与世界杯”，而是它如何通过“葡萄牙 x 西班牙国家队 / 门店周边”回应“把两队和两代球星的阵营选择变成咖啡杯上的公开表达”这一业务问题。

资源如何变成行动

进入路径

葡萄牙 x 西班牙国家队 / 门店周边

资源组织

围绕“把两队和两代球星的阵营选择变成咖啡杯上的公开表达”配置球星、球队、授权、商品、渠道或海外服务，而不是只做单一海报。

场景落点

根据品类落在门店、货架、礼赠、家庭观赛、出行或海外本地市场的具体触点。

赛后去向

通过收藏、复购、线索、渠道或交付案例，决定这项资源能否留下来。

动作拆解

  • 以“葡萄牙 x 西班牙国家队 / 门店周边”建立进入世界杯讨论的明确资格。
  • 把“把两队和两代球星的阵营选择变成咖啡杯上的公开表达”落实到杯套、保温杯、门店、App 点单、社交晒单与会员，避免只停留在赛事口号。
  • 面向葡萄牙、西班牙球迷、咖啡用户与年轻消费者设计看见、参与与行动三层触点。
  • 复盘时按周边领取、售罄、订单增量、会员、UGC 与复购拆开记录，不把曝光直接等同于业务效果。
可复用的方法高频杯身是低成本应援媒体，但要通过领取规则和产品设计把曝光转成到店与复购。

传播与业务机制

传播机制

国际赛事提供公共话题，中国品牌需要用明确的本土产品语言或海外市场语言完成翻译。

参与机制

低门槛商品、互动、内容或线下体验负责让泛球迷也有参与理由。

业务机制

真正的回报通常发生在商品、渠道、服务或海外市场，而不只在国内声量。
