Dove：The Game Is Ours

借男子世界杯的最大声量，讨论女孩为何离开运动

已核验官方个人护理 / 女童运动自信待补官方片与移动活动图

案例发生了什么

Dove 作为官方个人护理赞助商，没有把男子世界杯只做成男性球星广告，而是用 The Game Is Ours 讨论身体羞耻如何让女孩退出运动，并以限定产品、资源与街头移动活动承接。

它解决的策略问题

这页要回答的不是“Dove：The Game Is Ours 是否参与世界杯”，而是它如何通过“官方个人护理 / 女童运动自信”回应“借男子世界杯的最大声量，讨论女孩为何离开运动”这一业务问题。

触点设计

赛场/转播建立权威感，内容、零售、活动或服务负责把一次看见变成多次接触。

商业承接

优先观察商品、门店、电商、会员或长期社区项目是否接住了赛事关注。

动作拆解

  • 把赛事注意力转向原本容易被忽略的人群。
  • 让社会议题与品牌长期的身体自信平台连贯。
  • 以产品、内容与资源链接出明确的行动而不是停在态度表达。
