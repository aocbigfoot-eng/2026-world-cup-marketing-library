Nike Reactland：穿上新鞋，立刻跑进自己的游戏世界

消费者穿着 Epic React 在跑步机上奔跑，自己的头像同步变成游戏角色，闯过一段横版世界。

制作方素材已核中国体感游戏 / 跑步机试鞋 / 个性化视频
执行主体Nike × Wieden+Kennedy Shanghai × UNIT9
发生时间2018-03
发生场景Epic React 上市 / 门店试鞋
证据状态W+K / UNIT9 项目页 + 现场图片

案例发生了什么

Nike Reactland 把门店试鞋改造成一段可玩的横版跑酷游戏。参与者先拍照生成个人头像，再穿上 Epic React 站上跑步机；系统把跑速映射到屏幕里的虚拟角色，跑者需要在城市、冰雪和熔岩等场景中前进与跳跃。UNIT9 项目页显示，体验在中国四家门店和一处快闪空间运行约一个月，结束后还会生成约 10 秒的个人短视频供分享。鞋底缓震不再靠店员讲解，而是在跑动、视觉反馈和可带走内容中被感知。

关键动作
  • 把传统试鞋必做的“跑几步”变成有起点、障碍和终点的游戏任务。
  • 用个人头像建立角色归属，让每位参与者看到的是自己的游戏版本。
  • 结束后自动生成可分享短视频，把门店体验延伸到社交传播。

传播与商业机制

试用即游戏

消费者必须真实穿鞋奔跑，产品试用被嵌进娱乐任务。

身体作手柄

跑速和动作直接控制角色，使脚感与游戏反馈同步发生。

一人一内容

个性化头像和视频把标准化装置变成个人社交素材。

可复用的方法不要在体验后再解释产品；让产品成为完成游戏的必需工具，并在结束时自动交付可分享的个人结果。

适用条件与风险

  • 跑步机、绿幕与多人排队需要现场人员持续维护，并照顾不同运动能力和安全边界。
  • W+K 曾自述参与者中有 48% 购买产品，该数字属于代理商案例口径，本站不视为独立审计结果。
